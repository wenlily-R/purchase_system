采购系统 · Linux 服务器部署说明
================================
1. 上传本压缩包到服务器, 解压:
   unzip 采购系统服务器部署包.zip -d /opt/purchase_system

2. 安装依赖:
   python3 -m venv /opt/purchase_system/venv
   /opt/purchase_system/venv/bin/pip install flask flask-cors

3. 启动(前台测试):
   cd /opt/purchase_system && venv/bin/python app.py
   # 默认监听 127.0.0.1:5899

4. 对外开放(二选一):
   A. 直接监听公网: 修改 app.py 最后一行 host='0.0.0.0', 用 nginx 反代 + HTTPS 更安全
   B. 推荐 nginx 反代:
      server { listen 80; server_name 你的域名或IP;
               location / { proxy_pass http://127.0.0.1:5899;
                            proxy_set_header Host $host; } }
      然后 systemctl restart nginx
      防火墙放行 80 端口: firewall-cmd --add-port=80/tcp --permanent && firewall-cmd --reload

5. 开机自启(可选):
   sudo tee /etc/systemd/system/purchase.service <<'EOF'
   [Unit]
   Description=ZhengCheng Purchase System
   After=network.target
   [Service]
   WorkingDirectory=/opt/purchase_system
   ExecStart=/opt/purchase_system/venv/bin/python /opt/purchase_system/app.py
   Restart=always
   [Install]
   WantedBy=multi-user.target
   EOF
   sudo systemctl enable --now purchase

6. 访问: http://服务器IP:80   (账号 admin / admin123)
   飞书回调地址填: http://服务器IP/api/feishu/callback

7. 注意: 数据库在 data/purchase.db, 备份它即可
