# 三方询价 · 商家报价页 计价口径 定稿（2026-09-12）

**定稿口径：商家录入「含税单价 + 税率」→ 系统自动倒算「不含税单价」（含税为基准）。**

适用于 `GET /inq/<token>` 外部报价页与 `POST /api/inquiry/vendor/<token>/quote`。本文件为口径唯一裁定记录，改这一页前先读本文件，不要按记忆或注释里的旧版本动手。

## 口径变更时间线（同一处被反向改过两次，务必对齐后再动）

| 版本 | 提交 | 方向 | 说明 |
|---|---|---|---|
| V11.270 | `95d4090` | 录含税 → 倒算不含税 | |
| V11.285 | `1e25125` | 录不含税 → 正算含税 | 曾被改成此方向 |
| V11.288 | `3ebbea5` | 录含税 → 倒算不含税 | **现行为准**：恢复含税口径，V11.285 作废 |

结论：**以 V11.288 为准，录入口径 = 含税单价**。后续若领导要求改为"录不含税"，须一次性定稿后再改，并同步更新本文件与回归测试，禁止两边各翻一次。

## 字段语义（两侧完全一致，与录入方向无关，勿混用）

| 字段 | 含义 | 用途 |
|---|---|---|
| `unit_price` | **含税单价** | 比价、分项定标、订单、合同、入库、导出全部按它计算 |
| `excl_price` | 不含税单价 | 增值税口径展示（发票/台账台账侧） |
| `tax_rate` | 税率(%)，默认 13，允许 0 | 价税换算，0% 时不放大 |

换算：`不含税 = 含税 ÷ (1 + 税率/100)`；`含税 = 不含税 × (1 + 税率/100)`。

## 现行实现要点（改动时须同步，漏一处商家就会按错口径填）

- 明细录入框 `id=ipi<i>`（含税单价，必填）；税率框 `id=tx<i>`；自动列 `id=exc<i>`（不含税）；行总价 `id=ut<i>`（= 含税单价 × 数量）；合计 `#total`
- 页头提示 / 表头"自动"标记 / 未填校验文案 / "填一个总价自动分摊"提示，四处文案都要与录入方向一致
- 服务端**以含税单价为基准**倒算不含税（不信前端传的不含税值，防篡改）；仅传 `excl_price` 的旧式提交走兼容分支正算含税
- 已报价回显取 `unit_price`；历史仅存不含税的报价按税率正算后回显
- "填一个总价自动分摊"按**数量**分摊（`总价 ÷ Σ数量`），合计即所填总价；原按行数平分的写法会让合计与所填总价不符（填 452 得 1356），已修
