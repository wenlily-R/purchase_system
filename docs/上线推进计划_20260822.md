# 采购系统上线推进计划(2026-08-22 ~ 2026-09-05)

> 节奏: 8月底内部试运行 → 9月初领导进场(先演示后操作)
> 原则: 一个人推进, 发现差异当场改, 不给领导看半成品

- [ ] 8/22 领导流程骨架补完: 入库自动标"暂估" + 发票红冲前端界面 + 入库单暂估/正式标签 + 未红冲暂估单提醒采购
- [ ] 8/23 设备维修类型正式化(申请单表单加"类型"下拉: 物资采购/设备维修) + 比价单测试数据清理(BX开头3条)
- [ ] 8/24 角色分菜单权限(采购/库房/财务/领导各看各的) + 发票核对窗口单独授权给采购
- [ ] 8/25 加人+设角色(用户提供名单, 教操作)
- [ ] 8/26 库房真实物资数据录入(30-50条) + 供应商 + 安全库存线 + 分类统一(后勤类→标准分类)

## 阶段二: 内部试运行(8/27-8/31, 5天)

- [ ] 8/27-31 真实业务跑通: 申请→采购→到货→暂估入库→发票红冲→月底三表
- [ ] 每日发现差异, 当场改(每天1-2处)
- [ ] 摸清线下发票/合同的真实形态, 系统跟着改
- [ ] 领导录签名 + 审批流按实际定(砍5级→按金额)
- [ ] 操作说明页(给领导/新手看的)

## 阶段三: 领导进场(9/1-9/5)

- [ ] 9/1-2 给领导演示+讲解(只看不操作)
- [ ] 9/5左右 领导开始用: 先开放查询+审批(能看流程、能批单, 不录单)

## 硬性前提(不能省)

- [ ] 领导进场前: 必须真实数据(不是测试电脑)
- [ ] 领导进场前: 必须内部试运行过(8/27-31)
- [ ] 隧道/钉钉API: 试用期免费顶着, 领导确认后再花钱

## 待实施(8/24 后天)

- [ ] **帐期功能**: 采购订单/供应商加"账期"(月结30天/60天等付款条件)相关支持
- [ ] **红冲完善**: 发票红冲流程的剩余部分(未定内容, 用户8/24再确认)

## 待确认事项

- [ ] 库房会签是否做(未拍板, 可砍)
- [ ] 固定地址方案(上线前定)
- [ ] 大额线金额定多少(询价决策用, 领导说了算)

## 暂存方案(系统跑顺后实施)

- [ ] **报损原因分析**(触发条件: 出现"某种物资反复买反复坏"的实际问题再上)
  - 报损单加3字段: 使用时长 / 损坏原因(断裂·穿孔·磨损到寿命·其他) / 关联采购批次
  - 目的: 月底统计区分"供应商质量问题 vs 厂里正常消耗", 支撑换供应商/囤货决策
  - 现在不做原因: 测试期填单负担 + 数据量小无统计意义 + 增加复杂度

- [ ] **退库功能**(触发条件: 试运行后出现"领多了/领错了/用不完退回库房"的实际需求再上)
  - 出库单加"退库"类型, 填退回数量 → 库存自动加回 + 留痕
  - 客林ERP有但咱们暂不做: 单库房+规模小, 先看真实业务是否需要
  - 明确不做: 内部调拨(单库房) / 条码扫码(需设备) / 批次精细(小厂用不上) / 借出归还(优先级低)
