# 入库验收系统优化方案(2026-08-19 待实施)

> 用户需求:入库验收按部门分类+细分,比客林ERP(图片1/2)更好更便捷,新手一接触就明白。
> 状态:方案已确认方向,暂未改代码(用户要求留存,稍后实施)

## 现状分析(对比客林ERP)
- 客林ERP:功能导航多模块(调拨/盘点/报溢/报损/请货/组装/货位)+入库单16列(多单位/进价/税率/含税进价/税额/品牌/条码/货位)
- 痛点:无部门维度、分类粗(只有仓库+货位)、新手门槛高(16列录入)
- 我们的优势:已有物资类别(categories)+仓库+审批流,缺"部门"维度

## 方案(核心:部门+类别双维度,新手三步入库)
1. 入库单顶部"三选三填":选物资×数量 / 选部门(新增,关键) / 类别自动带出 / 采购验收人自动带出登录人
   - 新手只需做两件事:选物资、选部门,其他全自动
2. 列表页两个筛选下拉:全部部门▼ 全部类别▼ + 搜索框
   - 选"财务部"→只看财务部入库;选"办公用品"→只看办公用品
3. 状态大标签:🔵待检验 → 🟡待入库 → 🟢已入库 → 🔴有不合格
4. 弱化复杂概念:入库单只保留 物资/规格/数量/单位/单价/金额/类别/部门;税率税额多单位条码自动算或隐藏
5. 新手引导:首页顶部一句话"入库三步:①选物资 ②选部门 ③提交"

## 对比表
| 维度 | 客林ERP | 我们 |
|------|---------|------|
| 部门归属 | 无 | 入库必选部门 |
| 分类 | 仓库+货位(物理) | 部门+类别(业务) |
