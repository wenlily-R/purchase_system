> 版本：V11.68（2026-08-24）
> 编写：温丽（采购系统负责人）
> 适用：领导查看 / 新手培训 / 试运行参考

## 一、系统能干什么（一句话）

系统把厂里的**采购全流程**数字化：从员工要东西 → 采购下单 → 厂家发货 → 库房收货 → 财务付款，每一步都留痕、可审批、有记录。

---

## 二、菜单结构（6大类）

系统顶部有6个导航按钮，侧边有详细菜单。不同角色登录后看到的页面功能一样，但**点开受权限的页面会提示"仅限xx角色使用"**。

| 导航按钮 | 对应页面 | 谁能看 |
|---------|---------|-------|
| 📊 工作台 | 数据看板、预警提醒 | 所有人 |
| ✅ 审批 | 待我审批的单据 | 所有人（有徽标显示待办数） |
| 📝 采购 | 采购申请、三方询价、订单、合同、供应商 | 采购员+财务+领导+管理员 |
| 📦 库房 | 入库验收、出库管理、库存查询、库存盘点 | 库管员+采购员（看库存）+领导+管理员 |
| 💰 财务 | 付款申请、费用登记、月度对账、合并开票、往来台账 | 财务+领导+管理员 |
| 📈 报表 | 三表导出（暂估/红冲/白入）、报表中心 | 所有人 |

### 侧边栏详细菜单（所有角色都能看到全貌）

**① 工作台**
- 数据看板：本月采购总额、缺货物料、待入库、待审批、超期应付等

**② 采购管理**
- 📝 采购申请：填需求单，带部门前缀单号（如SC2026082401）
- 🔍 三方询价：选了商家报价，生成比价表
- 📋 采购订单：询价选定后自动生成，或手工新建
- 📄 合同管理：订单通过后生成合同，支持月结汇总
- 🏢 供应商：厂家信息管理

**③ 仓储库存**
- 📦 入库验收：货到点收，分归属部门，支持暂估/正式
- 📤 出库管理：领用出库，记录领取人/领取部门
- 📦 库存查询：看当前库存数量（库管员/员工看不到价格）
- 📋 库存盘点：定期盘点，差异自动生成报溢/报损单

**④ 财务往来**
- 💰 付款申请：给供应商付款
- 💸 费用登记：运输费/差旅费/维修费等
- 📊 月度对账：与供应商核对账目
- 🧾 合并开票：多笔订单合并开发票
- 🔍 往来台账：与每家供应商的收支明细

**⑤ 审批中心**
- 所有待我审批的单据列表，按类型分组

**⑥ 报表中心**
- 月底三表导出（暂估/红冲/白入Excel）
- 各类业务报表

## 三、核心业务流程（从左到右看）

### 流程总览图

```
员工口头要物资
    ↓
【采购申请】（采购员代填，系统自动查库存）
    ↓
【审批】（金额分级：≤500免批，>500走钉钉）
    ↓
【三方询价】（选≥3家商家报价）
    ↓
【比价定标】（≤500直接生效，>500审批）
    ↓
【采购订单】（自动生成，带供应商/金额/交期）
    ↓
【合同】（现结逐单，月结月底汇总）
    ↓
【到货验收】（库房点收，生成入库单）
    ↓
【发票红冲】（登记发票号，匹配暂估单冲红）
    ↓
【月底三表】（导出Excel给财务）
    ↓
【付款申请】→【付款】→ 完成
```

---

### 第一步：采购申请

**谁用：** 采购员（员工口头提需求，采购员代填）

**入口：** 侧边栏「采购管理 → 采购申请」

**功能：**
- 新建申请单：选部门 → 加物资行（名称/规格/数量/用途/参考价）→ 提交
- 申请单类型：物资采购 / 设备维修（灰色标签区分，不新建页面）
- 单号规则：部门前缀+当天总序（生产=SC，财务=CW，机电=JD…）
- **填物资时自动查库存**：输入物资名，系统显示「🔵库存X个」或「🔴库存0需采购」
- 每行物资可附图（打印时插到备注栏）
- 目标到货日：选填，不填不显示
- 提交后走审批流（金额分级）

**审批规则：**
- ≤500元：采购员自决，直接生效
- >500元：走钉钉审批（邢果→李苗苗→总经理，按金额分级）
- 审批通过后状态变为「已通过」，可发起三方询价

---

### 第二步：三方询价

**谁用：** 采购员

**入口：** 侧边栏「采购管理 → 三方询价」

**功能：**
- 发起询价：从「已通过但未询价」的申请单中选，选≥3家供应商
- 每家生成专属报价链接（免登录，商家手机就能报价）
- 商家报价页：每行填单价+数量→自动算总价，填交付日期+质保时间
- 截止时间：发起时可选1/2/3/7/15/30天后截止
- 选中商家：查看比价表（每物料一行，三家单价/总价并排），点「选中」
- 选中后：
  - ≤500元：自动生成订单，直接生效
  - >500元：自动生成订单，进入「定标审批」

**比价表特点：**
- 每物料一行，三家单价/总价/备注并排
- 最低单价标红加粗
- 可导出Excel（含决策备注）

---

### 第三步：采购订单

**谁用：** 采购员

**入口：** 侧边栏「采购管理 → 采购订单」

**功能：**
- 手工新建：选供应商 → 加物资行 → 选交易模式（货到付款/月结/预付等）→ 提交
- 询价选中自动带出：物资/数量/参考价自动填好
- 订单状态流转：草稿 → 待审批 → 已通过 → 已签合同 → 部分入库 → 已入库
- 订单详情可见：申请单来源、询价单来源、合同关联
- 下载打印：Excel格式，含签字区

**交易模式（帐期）：**
- 现结：逐单生成合同
- 月结：多张订单月底汇总成一份月度合同

---

### 第四步：合同管理

**谁用：** 采购员/领导

**入口：** 侧边栏「采购管理 → 合同管理」

**功能：**
- 手工新建合同
- 订单通过后自动生成合同（现结逐单）
- 月结汇总：月底前按厂家汇总多张订单，生成一份月度合同
- 合同模板：Word模板填充（买卖框架模板）
- 下载打印：Excel含签字区

**月结汇总流程：**
1. 合同管理页点「📅 月结汇总」
2. 看到当月所有月结订单按厂家分组
3. 点「📄 生成月度合同」→ 自动生成一份合同，关联所有订单

---

### 第五步：供应商管理

**谁用：** 采购员/财务

**入口：** 侧边栏「采购管理 → 供应商」

**功能：**
- 新增/编辑供应商：名称/联系人/电话/税号/开户行/账号
- 供应商列表：可查看历史合作（订单数/总金额）
- 报价历史：某供应商的报价记录

---

### 第六步：入库验收

**谁用：** 库管员（采购员也可看，因为要发票核对）

**入口：** 侧边栏「仓储库存 → 入库验收」

**功能：**
- 手工新建入库单：选部门 → 选物资 → 填实收数量 → 提交审批
- 自动入库单：订单审批通过后自动生成「待入库」记录（合同生效后自动）
- 到货提醒：自动单显示「📦 到货提醒」，库房点「✅ 确认到货」→ 状态变「入库中」
- 提交审批：库房点「📤 提交审批」→ 走审批流
- 审批通过后：
  - 默认**暂估入库**（橙底标签「暂估」）
  - 库存自动增加
  - 库存流水记录

**入库单字段：**
- 入库日期 / 归属部门 / 供应商 / 申请单号
- 物资明细（名称/规格/单位/申请数量/实收数量）
- 暂估金额（合同价）
- 验收照片/视频（必传/选传）

---

### 第七步：出库管理

**谁用：** 库管员

**入口：** 侧边栏「仓储库存 → 出库管理」

**功能：**
- 新建出库单：选物资 → 填领用数量 → 填领取人/领取部门/用途 → 提交审批
- 审批通过后：库存自动减少，生成出库流水
- 出库记录：可查看历史出库（带领取人/部门）

---

### 第八步：库存查询

**谁用：** 所有人（库管员/员工看不到价格）

**入口：** 侧边栏「仓储库存 → 库存查询」

**功能：**
- 库存列表：物资名/规格/单位/数量/仓库/供应商
- 分类筛选：按类别过滤
- 部门筛选：按归属部门过滤（入库时选的部门）
- 低库存预警：红色标签显示低于安全线的物资
- 一键补货：预警物资点「🛒 一键补货」→ 自动生成采购申请
- 库存溯源：点「🔍 溯源」→ 看该物资的入库/出库流水

---

### 第九步：库存盘点

**谁用：** 库管员

**入口：** 侧边栏「仓储库存 → 库存盘点」

**功能：**
- 新建盘点单：选仓库 → 选物资（可选全部）→ 填实盘数量
- 提交盘点：系统自动对比账面数量
- 差异处理：
  - 数量一致：盘点完成
  - 数量不一致：自动生成报溢/报损单（待审批）
- 报溢/报损审批通过后：库存调整

**报溢/报损：**
- 手动创建：多了用报溢，少了/坏了用报损
- 盘点差异自动生成
- 审批通过后库存调整，记录流水

### 第十步：发票红冲（领导流程核心）

**谁用：** 采购员（勾发票）/ 库管员（看暂估单）

**入口：** 入库验收列表 → 暂估单操作列「🧾 发票核对」

**功能：**
- 发票核对弹窗：
  - 入库单号（只读）
  - 发票号（必填）
  - 发票金额（必填）
  - 发票类型：增值税专用发票 / 增值税普通发票
- 提交红冲：
  - 暂估单状态变「已红冲」（绿底标签）
  - 库存流水记录红冲
  - 发票信息存入系统

**月底三表（报表中心）：**
- 暂估表：已入库但未红冲的单据（发票未回）
- 红冲表：已红冲的暂估单
- 白入表：直接正式入库的单据（不走暂估）
- 自动核对：检查三表差异，提示异常

## 四、审批流程（钉钉/飞书）

### 审批类型

| 单据类型 | 审批节点 | 触发条件 |
|---------|---------|---------|
| 采购申请 | 部门负责人 → 分管领导 → 总经理 | 金额>500 |
| 三方询价定标 | 部门负责人 → 分管领导 → 总经理 | 金额>500 |
| 采购订单 | 部门负责人 → 分管领导 → 总经理 | 金额>500 |
| 入库验收 | 部门负责人 → 库管主管 | 所有入库单 |
| 出库管理 | 部门负责人 → 库管主管 | 所有出库单 |
| 付款申请 | 财务 → 分管领导 → 总经理 | 所有付款 |
| 报溢/报损 | 部门负责人 → 库管主管 | 所有报溢报损 |

### 审批特点
- 审批通过→系统自动同步状态
- 审批驳回→单据打回，申请人可见意见
- 审批办结→通知发起人（系统站内信+钉钉工作通知）

## 七、注意事项

### 关于金额分级
- 小额≤500元：采购员自决，直接生效，不走审批
- 大额>500元：走钉钉审批（邢果→李苗苗→总经理）
- 金额阈值可根据实际情况调整（领导定）

### 关于暂估/红冲
- 入库默认暂估（货到发票未到先估）
- 收到发票后，采购员在系统上登记发票号+金额，点击「发票核对」
- 系统自动红冲暂估，生成正式入库记录
- 月底三表导出给财务

### 关于月结
- 订单创建时选「月结」
- 月底前按厂家汇总，生成一份月度合同
- 月结合同关联所有订单，一次性付款

### 关于备份
- 系统每天自动备份数据库
- 备份文件：`data/backup_YYYYMMDD_HHMMSS.db`
- 紧急恢复：替换 `data/purchase.db` 为备份文件
