## 模块执行顺序（按文档一到九 + 补充项，每模块内再分子项逐步做）
先做最核心/用户最痛的点，剩余按序推进。每完成一个模块跑回归+如实记录。

### 模块一：合同与发票管理（1.1 发票条款 / 1.2 发票节点提醒 / 1.3 发票统计报表）
- 合同模板/表单加字段：发票条款说明、预计首次开票时间、预计全部开票完成时间；合同详情/导出/钉钉附件同步
- 发票节点自动提醒（系统内+钉钉），采购专员可标记催收状态、登记发票号码/金额/收票日期
- 报表中心发票统计：供应商维度/合同维度、按年月周日月展示、可筛选可导出、超期标红预警
注意：合同模板是用户上传的 docx（买卖合同.docx），加字段要兼容——先看合同表单/生成逻辑

### 模块二：采购申请与库存权限
- 2.1 采购申请审批流加【库管审核】节点开关（系统设置可视化启停），库管可看明细/填意见/改建议数量，记录日志
- 2.2 库存查看权限按角色矩阵（提报员❌/采购专员❌/采购主管✅/采购总监✅/厂长✅/总经理✅/财务领导✅/库管✅）——注意系统现有角色（系统管理员/分管领导/采购员/财务/员工）需映射，先在系统设置的角色权限里对齐
- 预留库存状态字段（正常/损坏/过期）不启用

### 模块三：三方询价防作弊（3.1 统一开标）—— 防作弊核心，用户最关心
- 询价单加【报价截止时间】（精确到时分）
- 截止前所有内部账号禁止看报价（显示"报价未开标，暂不可查看"）；供应商可正常提交/修改
- 截止后自动解锁、统一展示、按价格从低到高排序；供应商截止后不可再改
- 仅采购主管+可延长截止时间并记日志
- 3.2 分项定标保留优化（展示每项物料各供应商报价/选定供应商/价格）——核查现有分项定标是否已满足

### 模块四：入库验收（4.1 集体验收 + 4.3 对账勾稽）
- 4.1 入库审批默认节点：计划提报员确认→采购专员确认→库管验收入库（可配置）；到货弹窗问"是否集体验收"，勾选则推送机电厂长/生产厂长/机修车间主任签字，完后再库管入库；维修返回件重点性能验收
- 4.3 库存流水来源标注+溯源+对账小统计页面（同规格不同型号分开统计）
- 4.2 分批验收已做只核查

### 模块五：维修采购独立流程（全新大模块）
- 五步流程：提报(设备/故障/更换部件/照片)→定损确认(机电厂长/生产厂长/机修车间主任)→厂家报价录入→维修变更二次确认(四方)→维修完成返库验收
