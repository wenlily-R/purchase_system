采购系统两台电脑同步修改说明
================================

一、原理(一句话)
两台电脑的代码通过一个"共享仓库"同步:
你改完 → 点"同步推送" → 代码传到共享仓库
他那边 → 点"同步拉取" → 代码更新到他电脑, 刷新页面就能看到

二、需要准备的东西
1. 一台电脑注册一个"码云 Gitee"账号(免费): https://gitee.com
   (或 GitHub 账号, 二选一)
2. 两台电脑都装上 Git:
   - Mac: 系统一般自带, 终端输入 git --version 有版本号即可
   - Windows: 下载安装 https://git-scm.com/download/win, 一路下一步

三、首次连接(只做一次)
1. 在码云上新建一个【私有】仓库, 名字随意, 比如 purchase_system
2. 把仓库地址发给维护人员, 由他配置好第一次推送
   (或者按仓库页面提示的 https 地址, 在两台电脑上分别执行:
    git remote add origin 仓库地址 )
3. 之后两台电脑都执行一次"同步拉取", 代码就一样了

四、日常使用(每次改完代码)
1. 改代码的电脑: 双击【同步推送.command】(Mac) 或运行推送命令
2. 另一台电脑: 双击【同步拉取.command】
3. 如果改了 app.py(后端代码), 拉取后要重启系统:
   - 关掉正在运行的 python 窗口, 重新运行"启动系统"
4. 如果只是改了页面(templates/index.html), 刷新浏览器即可, 不用重启

五、重要提醒
1. 数据库(purchase.db)不会同步, 每台电脑各用各的数据。
   - 正式数据以主电脑为准, 测试/开发用另一台没关系
   - 如果两人要共用同一份业务数据, 请只用一台电脑跑系统, 另一台只改代码
2. 两人同时改同一个文件时, 后推送的人可能会提示冲突, 需要人工确认,
   建议: 改之前先"同步拉取"一次, 改完尽快推送
3. 代码里没有密码和密钥(飞书/钉钉的密钥存在数据库里, 不会上传),
   但仓库务必选【私有】, 不要公开

六、问维护人员要的(已配置好的部分)
- 本机仓库已初始化, 数据目录和运行文件已正确排除
- 两个一键同步脚本已就位
- 只差: 远程仓库地址(见第三条)
